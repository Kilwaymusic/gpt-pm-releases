## Desktop and Mobile

Run the Desktop EXE on your Windows PC. Install the APK on your Android phone.

In Desktop, open **Remote → Pair** in the lower-left corner. Scan the QR code with Mobile to access your PC's Roles and Plans. The phone remembers the PC after pairing. To add another PC, open **Your PCs → Add PC** in Mobile.

Keep Desktop running and the PC awake for remote access. Closing the Desktop window sends it to the tray so work can continue. Mobile needs an internet connection and a running Desktop. Bridge is a separate app and is not required for Mobile.

## Updating

The download links above always point to the latest complete build. New downloads are published after the automated checks and Windows/Android builds succeed.

Replace the Windows EXE to update Desktop or Bridge. Install a new APK over the existing Android app to preserve paired PCs; do not uninstall the app first.

These are unsigned Windows builds and Android builds signed with the existing development key. They are not store releases. `SHA256SUMS.txt` contains the hashes of the three app downloads.

This repository contains downloads and usage notes. Application source code and its Git history are maintained separately. GitHub's automatic **Source code** archives contain only this distribution repository's files.
